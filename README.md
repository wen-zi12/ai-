# Focusly · 专注番茄钟网页应用

一个纯前端实现的专注番茄钟网页示例，打开即用，无需后端与任何外部依赖。

## 功能

- 专注 / 短休息 / 长休息三种模式切换（25 / 5 / 15 分钟）
- 环形进度倒计时，开始、暂停、重置
- 今日完成轮次、连续轮次、累计专注分钟统计
- 今日待办清单，回车添加，点击可切换完成状态，点 × 可单条删除
- 批量删除：点「批量删除」进入选择模式，勾选后一键删除，支持全选 / 取消
- 数据本地持久化：待办、统计、计时状态保存在浏览器 localStorage，刷新不丢失；跨天自动重置当日统计

## 使用

直接用浏览器打开 `index.html` 即可，桌面与手机浏览器均支持。

## 部署

把 `index.html` 改名后（已命名为 `index.html`）放入任意静态托管服务，例如：

- GitHub Pages：新建 Public 仓库 → 上传文件 → Settings → Pages → 选择 `main` 分支 `/ (root)`
- Vercel / Netlify / Cloudflare Pages：拖拽文件夹即可部署

## 说明

- 单文件 HTML/CSS/JS，无任何外部依赖，可离线运行。
- 所有数据保存在浏览器 localStorage 中，刷新页面不会丢失（换浏览器 / 清缓存会重置）
